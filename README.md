# 📱 QR Code Generator

A simple and user-friendly **QR Code Generator** built using HTML, CSS, and JavaScript. Enter any text or URL and generate a QR code instantly.

## 🚀 Live Demo

[QR Code Generator](https://js-projects-ksgk.vercel.app/)

## ✨ Features

* 🔗 Generate QR codes from text or URLs
* ⚡ Generate QR code with a single click
* 👀 Preview the generated QR code
* 📥 Download the generated QR code
* ❌ Close the generated QR code
* 🎨 Simple and clean user interface
* 🌐 Deployed using Vercel

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — QR generation and user interactions
* **Vercel** — Deployment

## 📂 Project Structure

```text
qr-code-generator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 How to Use

1. Open the [Live Demo](https://js-projects-ksgk.vercel.app/).
2. Enter a **text or URL**.
3. Click **Generate QR Code**.
4. View the generated QR code.
5. Click **Download QR** to save it.
6. Use **Close** to close the QR preview.

## ⚙️ How It Works

```text
User enters text / URL
        ↓
Click "Generate QR Code"
        ↓
JavaScript processes the input
        ↓
QR Code is generated
        ↓
QR Code is displayed
        ↓
User can download the QR Code
```

## 🔮 Future Improvements

* 📋 Copy-to-clipboard option
* 🎨 Custom QR code colors
* 🖼️ Logo/image support
* 📐 Different QR code sizes
* 📜 QR generation history

# 🎮 Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe game** built using HTML, CSS, and JavaScript. The project focuses on DOM manipulation, event handling, game logic, and dynamic UI updates.

## ✨ Features

* ❌ Player X and ⭕ Player O gameplay
* 🎮 Interactive game board
* 🏆 Automatic winner detection
* 🤝 Draw detection
* 🔄 Restart game functionality
* 🎨 Simple and responsive interface
* ⚡ Built entirely with vanilla JavaScript

## 🛠️ Technologies Used

* **HTML5** — Game structure
* **CSS3** — Styling and layout
* **JavaScript** — Game logic and DOM manipulation
* **Vercel** — Deployment

## 📂 Project Structure

```text
tic-tac-toe/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 How to Play

1. Open the Tic-Tac-Toe application.
2. Player X starts the game.
3. Players take turns selecting an empty cell.
4. The first player to get three symbols in a row wins.
5. If all cells are filled without a winner, the game ends in a draw.
6. Click **Restart** to play again.

## ⚙️ How It Works

```text
Player selects a cell
        ↓
JavaScript updates the board
        ↓
Check winning combinations
        ↓
Winner found?
   ↙          ↘
 Yes           No
 ↓              ↓
Display       Check for draw
winner           ↓
              Continue game
```

# 📊 LeetCode Metrics

A simple **LeetCode Metrics Dashboard** built using HTML, CSS, and JavaScript. Enter a LeetCode username to fetch and display problem-solving statistics.

## 🚀 Live Demo

[LeetCode Metrics](https://js-projects-hufy.vercel.app/)

## ✨ Features

* 👤 Search LeetCode statistics using a username
* 📊 Display solved problems by difficulty
* 🟢 Show Easy problems solved
* 🟡 Show Medium problems solved
* 🔴 Show Hard problems solved
* ⚡ Fetch metrics with a single click
* 🎨 Simple and clean user interface
* 🌐 Deployed using Vercel

## 🛠️ Technologies Used

* **HTML5** — Structure
* **CSS3** — Styling and layout
* **JavaScript** — Data fetching and UI updates
* **LeetCode API** — Retrieving user statistics
* **Vercel** — Deployment

## 📂 Project Structure

```text
leetcode-metrics/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 🎯 How to Use

1. Open the [Live Demo](https://js-projects-hufy.vercel.app/).
2. Enter a **LeetCode username**.
3. Click the **Fetch** button.
4. The application retrieves the user's statistics.
5. View the **Easy, Medium, and Hard** problem counts.

## ⚙️ How It Works

```text
User enters LeetCode username
        ↓
Click "Fetch"
        ↓
JavaScript requests user data
        ↓
LeetCode statistics are retrieved
        ↓
Data is processed
        ↓
Easy / Medium / Hard counts are displayed
```
