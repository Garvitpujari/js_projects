# QR Code Generator 📱

A simple and user-friendly **QR Code Generator** built using HTML, CSS, and JavaScript. Enter any text or URL and generate a QR code instantly.

## 🚀 Live Demo

[QR Code Generator](https://js-projects-ksgk.vercel.app/)

## ✨ Features

* 🔗 Generate QR codes from text or URLs
* ⚡ Generate QR code with a single click
* 👀 Preview the generated QR code
* 📥 Download the generated QR code
* ❌ Close the generated QR code
* 🎨 Simple and clean user interface
* 🌐 Deployed using Vercel

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and layout
* **JavaScript** — QR generation and user interactions
* **Vercel** — Deployment

## 🎯 How to Use

1. Open the [Live Demo](https://js-projects-ksgk.vercel.app/).
2. Enter a **text or URL** in the input field.
3. Click **Generate QR Code**.
4. Your QR code will be displayed.
5. Click **Download QR** to save the generated QR code.
6. Use **Close** to close the QR code preview.

## ⚙️ How It Works

The application follows a simple workflow:

```text
User enters text / URL
        ↓
Click "Generate QR Code"
        ↓
JavaScript processes the input
        ↓
QR Code is generated
        ↓
QR Code is displayed
        ↓
User can download the QR Code
```

## 💻 Run Locally

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate to the project directory:

```bash
cd qr-code-generator
```

Open `index.html` in your browser.

No backend server is required.
